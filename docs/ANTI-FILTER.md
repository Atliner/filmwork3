# پنهان‌کردن IP سرور و دور زدن فیلتر — راه‌اندازی ارزان

> هدف: کاربر هرگز IP سرور اصلی را نبیند. اگر دامنه فیلتر شد، **دامنه** عوض شود،
> نه سرور. با این ساختار، سرور دست‌نخورده می‌ماند و فقط یک ساب‌دامنهٔ تازه می‌سازیم.

```
کاربر ──► دامنه (پشت Cloudflare)  ──►  هاست اشتراکی (فقط همین IP دیده می‌شود)
                                          │
                                          └──► سرور/ورکر واقعی (IP پنهان)
```

سه لایه، از کم‌هزینه به کامل:

| لایه | چه چیزی مخفی می‌شود | هزینه | کی بس است |
|---|---|---|---|
| **۱. Workers** | IP سرور (سروری وجود ندارد) | صفر | وقتی خود سایت روی Cloudflare است |
| **۲. آینهٔ PHP روی cPanel** | IP کلادفلر/سرور؛ فقط IP هاست دیده می‌شود | هزینهٔ هاست | فیلتر شدن `*.workers.dev` و دامنه‌ها |
| **۳. آینهٔ Node روی cPanel** | هیچ وابستگی به کلادفلر | هزینهٔ هاست | وقتی کلادفلر هم در دسترس نیست |

---

## ۱) کوتاه‌ترین راه: فقط Workers

آدرس پیش‌فرض `*.workers.dev` در ایران معمولاً فیلتر است، پس همان روز اول یک
**دامنهٔ شخصی پشت Cloudflare** به Worker وصل کن (Custom Domain). در این حالت:

- DNS کلادفلر، A/AAAA واقعی را نمی‌دهد؛ رکورد پروکسی‌شده فقط IPهای کلادفلر را نشان می‌دهد؛
- اگر دامنه فیلتر شد، ساب‌دامنهٔ تازه بساز (پایین) و Worker همان است.

## ۲) آینهٔ PHP روی هاست (توصیه‌شده برای ایران)

سرور اصلی (Worker یا هر جای دیگر) می‌ماند؛ هاست اشتراکی «درب» می‌شود:

1. سایت اصلی را بالا بیاور و آدرسش را داشته باش (مثلاً `https://film.example.workers.dev`).
2. در cPanel → `public_html`:
   - `index.php` ← از `hosting/php/index.php` (مقدار `UPSTREAM` را عوض کن)
   - `.htaccess` ← از `hosting/php/.htaccess`
3. AutoSSL را روشن کن و یک ساب‌دامنه به این هاست وصل کن (مثلاً `play.example.ir`).
4. در Cloudflare، همان ساب‌دامنه را **پروکسی‌شده (نارنجی)** به IP هاست بده.
   رکورد A باید IP هاست باشد، نه سرور اصلی.

نتیجه: `dig play.example.ir` فقط IP کلادفلر را می‌دهد و `curl -I https://play.example.ir`
هیچ نشانه‌ای از سرور اصلی ندارد (هدرهای `Server` بازنویسی می‌شوند، `Set-Cookie`
بدون Domain و `Location`ها بازنویسی می‌شوند).

> ویدیو در این حالت دو بار رد می‌شود (کاربر → هاست → سرور). برای ترافیک بالا،
> پخش آنلاین را از لبه‌ها (`docs/ONLINE-PLAYER.md`) سرو کن تا مسیر ویدیو از هاست
> نگذرد، یا از مسیر ۳ استفاده کن.

## ۳) آینهٔ Node روی هاست (کاملاً مستقل)

اگر می‌خواهی سایت نه به کلادفلر و نه به سرور دیگری وابسته نباشد:

```bash
cd ~/filmwork && PORT=8080 node hosting/server.mjs
```

و در `.htaccess` دامنه:

```apache
RewriteEngine On
RewriteRule ^(.*)$ http://127.0.0.1:8080/$1 [P,L]
```

داده‌ها در `hosting/data/*.sqlite` می‌مانند؛ IP واقعی همان IP هاست است (که خودش
پشت Cloudflare پنهان می‌شود). راهنمای کامل: `docs/SHARED-HOSTING.md`.

---

## عوض‌کردن دامنه وقتی فیلتر شد (تکرارپذیر)

**دستی (۲ دقیقه):** در Cloudflare → DNS → Add record:

| Type | Name | Content | Proxy |
|---|---|---|---|
| CNAME | `play2` | `film.example.workers.dev` یا IP/هاست هاست | 🟠 Proxied |

**خودکار:**

```bash
CF_API_TOKEN=… CF_ZONE_ID=… TARGET=film.example.workers.dev SUB=play2 \
  node scripts/rotate-domain.mjs
```

خروجی، آدرس تازه و قدم‌های بعدی (BotFather، `SITE_PUBLIC_ORIGIN`، APK/EXE) را
چاپ می‌کند. سرور و داده‌ها دست نمی‌خورند.

پس از ساخت دامنهٔ تازه:

1. **BotFather → /mybots → Bot Settings → Domain / Mini App** ← دامنهٔ تازه
2. **تنظیمات سایت → آدرس عمومی** (`SITE_PUBLIC_ORIGIN`) ← اگر می‌خواهی لینک‌ها
   همیشه از همین دامنه ساخته شوند (توکن‌ها میزبان‌محور نیستند)
3. **برنامه‌ها**: `SITE_URL=https://play2.…` و بیلد تازه، یا در صفحهٔ انتخاب آدرس
   همان آدرس را وارد کن (APK/EXE دوباره لازم نیست اگر صفحهٔ انتخاب آدرس داشته باشد)

## پایش خودکار (بفهم قبل از کاربر)

روی هاست، هر ۵ دقیقه:

```
*/5 * * * * cd /home/USER/filmwork && /usr/bin/node scripts/mirror-health.mjs https://play.example.ir https://film.example.workers.dev >> health.log 2>&1
```

`mirror-health` برای هر آدرس `UP/DOWN`، کد وضعیت و زمان پاسخ را می‌نویسد و اگر
همه بخوابند با کد خروج ۱ برمی‌گردد (برای هشدار در cron/ایمیل هاست). مسیر پیش‌فرض
`/api/health` است که بدون خواندن دیتابیس پاسخ می‌دهد.

## نکته‌های امنیتی

- IP هاست را در هیچ‌جا عمومی نکن؛ رکوردهای Cloudflare را **همیشه** پروکسی‌شده بگذار.
- روی هاست، دسترسی مستقیم به `index.php` از IP خام را ببند (`.htaccess` با
  `Require`/`deny from all` روی مسیرهای داخلی) تا کسی با IP خام، دامنه را دور نزند.
- HTTPS فقط از Cloudflare (Full/Strict) + AutoSSL هاست؛ `http://` را ریدایرکت کن.
- `hosting/data/` (SQLite) و `.env` هرگز داخل `public_html` نباشند.
- `UPSTREAM` در `hosting/php/index.php` را با `https://` بده و تا جای ممکن
  آدرس مبدأ را فقط در فایل سمت سرور نگه دار.
